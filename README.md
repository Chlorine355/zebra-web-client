# Сборка

Проект собирается автоматически с помощью workflow при каждом пуше в main и кладется в ветку build

## Шаг 1: установка библиотек

Для работы с проектом нужен npm и node.

```sh
npm install
```

## Шаг 2: сборка

```sh
npm run build
```
## Разработка
Для открытия сервиса для разработки с hot module reload (обновлением страницы сразу после изменения кода, без перезагрузки страницы) используем скрипт:
```sh
npm run dev
```
Для предпросмотра production build:

```sh
npm run build
npm run preview
```
